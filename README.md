# JumpKingFMV

영상을 보다가 선택지와 QTE로 다음 분기를 고르는 Unity FMV(Full Motion Video) 게임입니다.

## 실행

- `JumpKingFMV.exe`를 실행합니다. 같은 폴더의 `JumpKingFMV_Data` 등 다른 파일도 함께 있어야 합니다.
- 1920×1080 전체 창 모드로 시작합니다. Alt+Enter로 창 모드로 바꿀 수 있습니다.

## 조작

- 마우스 클릭으로 선택지를 고르고 QTE에 반응합니다.
- 분기도는 드래그로 이동하고 마우스 휠로 확대·축소합니다. 열린 카드를 누르면 그 분기부터 다시 볼 수 있습니다.

## 저장

진행 기록과 업적은 아래 파일에 자동으로 저장됩니다.

```
%USERPROFILE%\AppData\LocalLow\DefaultCompany\JumpKingFMV\save.json
```

메인 메뉴의 세이브 초기화 버튼으로 기록을 지울 수 있습니다.
